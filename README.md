# Практична робота: файлові системи та обслуговування дисків

**Клас:** 8 · **Час:** 35 хв · **ОС:** Windows 11 · **Права адміністратора не потрібні**

**Онлайн-бланк:** відкрийте сторінку GitHub Pages цього репозиторію.

> ⚠️ Нічого не видаляйте і не змінюйте, крім очищення в завданні 6.
>
> Термінал: `Win + X` → **Термінал** (не «адміністратор»). Вставити команду — `Ctrl + V`, виконати — `Enter`.

## Довідка

| Файлова система | Де використовується | Макс. розмір файлу |
|---|---|---|
| FAT32 | флешки, старі пристрої | 4 ГБ |
| exFAT | флешки для Windows і macOS | практично без обмежень |
| NTFS | диски Windows | практично без обмежень |
| ext4 | Linux, Android | 16 ТБ |
| APFS | macOS, iOS | практично без обмежень |

**Форматування** створює на диску файлову систему, усі дані знищуються. Швидке очищує лише таблицю файлів, повне ще й перевіряє диск на пошкоджені сектори.

**Кластер** — найменша ділянка диска, яку файлова система виділяє під файл. Тому файл займає на диску трохи більше місця, ніж його розмір.

**Фрагментація** — коли частини файлу лежать у різних місцях диска, і HDD читає їх повільніше. **Дефрагментація** збирає частини файлів разом. SSD дефрагментація не потрібна.

| | Логічне ушкодження | Фізичне ушкодження |
|---|---|---|
| **Що це** | помилки даних або файлової системи | несправність самого пристрою |
| **Причини** | вимкнення живлення, віруси, неправильне виймання флешки | удар, перегрів, волога, стрибок напруги, знос |
| **Усунення** | програмно | ремонт або заміна |

# Частина 1. Дані дисків

## 1. Файлова система дисків

`Win + E` → **Цей ПК** → виділіть диск → `Alt + Enter` (або ПКМ → **Властивості**). Файлова система — на вкладці **Загальні**, під рядком «Тип».

| Диск | Файлова система | Обсяг | Вільно |
|---|---|---|---|
| C: | | | |
| D: | | | |

## 2. Обсяг диска в байтах

У Терміналі виконайте:

```powershell
Get-CimInstance Win32_LogicalDisk | Format-Table DeviceID, FileSystem, Size, FreeSpace
```

Переведіть значення для C: і D: у ГБ (поділіть на 1024 тричі, округліть до десятих).

| Диск | Параметр | Байти | ГБ |
|---|---|---|---|
| C: | Size | | |
| C: | FreeSpace | | |
| D: | Size | | |
| D: | FreeSpace | | |

## 3. Тип накопичувача

`Ctrl + Shift + Esc` → **Продуктивність**. Знайдіть диски з позначками **(C:)** і **(D:)** у назві, наприклад «Диск 0 (C:)». Модель — у правому верхньому куті.

| Диск | Номер | Тип (SSD / HDD) | Модель | Обсяг |
|---|---|---|---|---|
| C: | | | | |
| D: | | | | |

Якщо C: і D: розташовані на одному фізичному диску («Диск 0 (C: D:)»), рядки будуть однакові.

# Частина 2. Дефрагментація

## 4. Дефрагментація вручну

Виконується на моделі диска в онлайн-бланку (справжня дефрагментація потребує прав адміністратора).

1. Запишіть фрагментованість до початку.
2. Зберіть кожен файл суцільно й по порядку: натисніть частину файлу, потім вільну клітинку.
3. Запишіть кількість своїх переміщень, натисніть **Автоматично** і порівняйте.

| Фрагментованість до | Мої переміщення | Переміщень автоматично | Фрагментованість після |
|---|---|---|---|
| | | | |

# Частина 3. Очищення диска

## 5. Огляд перед очищенням

`Win + R` → `cleanmgr` → **C:** → **OK**. Запишіть дані й натисніть **Скасувати**. Повторіть для **D:**. Найбільшу категорію в онлайн-бланку обирають зі списку.

| Диск | Можна звільнити | Найбільша категорія |
|---|---|---|
| C: | | |
| D: | | |

## 6. Очищення через «Сховище»

1. `Win + I` → **Система** → **Сховище**. Якщо з’явиться запит пароля адміністратора — натисніть **Ні** і продовжуйте.
2. Запишіть, скільки місця на диску C: використано і скільки всього: ____ з ____
3. Відкрийте **Тимчасові файли**. Зніміть усі позначки, позначте **лише** «Тимчасові файли» і «Ескізи». Запишіть їхні розміри в стовпець «До».
4. **Видалити файли** → підтвердіть видалення. Запишіть нові розміри в стовпець «Після».

| Категорія | До | Після |
|---|---|---|
| Тимчасові файли | | |
| Ескізи | | |

Windows не видаляє файли, які зараз використовуються, тому «Після» може бути не нуль.
